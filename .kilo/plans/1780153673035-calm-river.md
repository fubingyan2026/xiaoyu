# encoder_alignment → foc_encoder 模块重构

## 目标

将 `applications/encoder_alignment.c/h` 重构为 `foc_q16/foc_encoder.c/h`：
1. 移动到 `foc_q16/` 目录
2. 按功能重新命名（encoder_alignment → foc_encoder）
3. 模块间解耦（消除全局变量依赖）
4. 支持多实例运行

## 当前架构问题

| 问题 | 描述 |
|------|------|
| 全局变量 | `g_encoder_calib`、`g_motor_flash_cfg` 全局唯一，无法多实例 |
| Flash 耦合 | `encoder_alignment_init()` 直接调用 `ef_get_env_blob()`，模块与 EasyFlash 强耦合 |
| 类型命名不一致 | `motor_flash_config_t`、`encoder_calibration_t` 命名不遵循 `foc_` 前缀规范 |
| 文件位置 | 放在 `applications/` 下，实际是 FOC 核心依赖模块 |

## 依赖关系全景

```
applications/encoder_alignment.c/h (当前)
  ├── 定义: motor_direction_t, motor_flash_config_t, encoder_calibration_t
  ├── 全局: g_encoder_calib, g_motor_flash_cfg
  ├── API: encoder_alignment_init(), encoder_detect_direction(), encoder_track_sector()
  │
  ├── 被 foc_q16/foc.h 引用 (motor_flash_config_t 在注释中)
  ├── 被 foc_q16/foc.c 调用 (encoder_track_sector + g_encoder_calib)
  ├── 被 foc_q16/foc_fsm.c 调用 (encoder_detect_direction + g_encoder_calib + g_motor_flash_cfg)
  ├── 被 applications/foc_task.c 调用 (encoder_alignment_init)
  ├── 被 applications/usart_protocol.c 引用 (g_encoder_calib, g_motor_flash_cfg)
  ├── 被 applications/flash_task.h 引用 (motor_flash_config_t)
  └── 被 applications/flash_task.c 引用 (g_motor_flash_cfg 在 default_env_set 中)
```

## 重构后的架构

```
foc_q16/foc_encoder.c/h (新)
  ├── 定义: foc_encoder_dir_t, foc_encoder_flash_t, foc_encoder_t
  ├── 无全局变量 (实例化上下文)
  ├── API: foc_encoder_init(), foc_encoder_detect_direction(), foc_encoder_track_sector()
  │
  ├── 被 foc_q16/foc.h 包含 (foc_encoder_t 嵌入 foc_context_t)
  ├── 被 foc_q16/foc.c 调用 (foc_encoder_track_sector)
  ├── 被 foc_q16/foc_fsm.c 调用 (foc_encoder_detect_direction)
  ├── 被 applications/foc_task.c 调用 (foc_encoder_init + EasyFlash 加载作为上层职责)
  ├── 被 applications/usart_protocol.c 引用 (通过 foc_get_encoder_ctx() 访问器)
  └── 被 applications/flash_task.c 引用 (通过 extern 或访问器)
```

## 类型重命名

| 旧名 | 新名 | 说明 |
|------|------|------|
| `motor_direction_t` | `foc_encoder_dir_t` | 编码器方向枚举 |
| `MOTOR_DIR_REVERSE` | `FOC_ENCODER_DIR_REVERSE` | 反向 |
| `MOTOR_DIR_NONE` | `FOC_ENCODER_DIR_NONE` | 未初始化 |
| `MOTOR_DIR_FORWARD` | `FOC_ENCODER_DIR_FORWARD` | 正向 |
| `motor_flash_config_t` | `foc_encoder_flash_t` | Flash 持久化数据 |
| `encoder_calibration_t` | `foc_encoder_t` | 编码器运行时上下文 |

## foc_encoder_t 结构设计

将原 `encoder_calibration_t` + `motor_flash_config_t` 合并为一个上下文：

```c
typedef struct {
    // === Flash 持久化数据（原 motor_flash_config_t） ===
    uint16_t angle_map[MAX_MOTOR_STEPS + 1];  // 角度校准查找表
    foc_encoder_dir_t flash_direction;        // 写入 Flash 的方向值

    // === 运行时校准状态（原 encoder_calibration_t） ===
    float electrical_angle;                   // 当前电角度 [0, 2π)
    foc_encoder_dir_t direction;              // 运行时方向
    int16_t current_sector;                   // 当前电扇区索引
    int16_t zero_offset;                      // 零位偏移
    int16_t step_delta[MAX_MOTOR_STEPS];      // 每个扇区增量
    int16_t current_step_delta;               // 当前扇区增量
    int16_t encoder_lines;                    // 编码器线数
    int16_t total_steps;                      // 总校准步数
    bool is_valid;                            // 校准数据有效标志
    int16_t invalid_sector_index;             // 无效扇区索引
} foc_encoder_t;
```

## Flash 策略（用户选择：flash_task.c 保持全局注册）

- `flash_task.c` 的 `default_env_set` 继续注册一个全局 `g_encoder_flash`（类型改为 `foc_encoder_flash_t`），由 EasyFlash 自动加载/保存
- `foc_encoder_init()` **不调用** `ef_get_env_blob()`，改为接收外部传入的已加载 flash 数据指针
- 编码器模块与 Flash 零耦合，Flash 持久化完全由应用层（flash_task.c）负责

## 实施步骤

### 1. 创建 `foc_q16/foc_encoder.h` — 新类型和 API 声明

从 `encoder_alignment.h` 迁移：
- 重命名所有类型：`motor_direction_t` → `foc_encoder_dir_t`、`motor_flash_config_t` → `foc_encoder_flash_t`、`encoder_calibration_t` → `foc_encoder_t`
- 重命名所有枚举值：`MOTOR_DIR_*` → `FOC_ENCODER_DIR_*`
- 配置常量（`ENCODER_RESOLUTION`、`MAX_MOTOR_STEPS` 等）继续从 `foc_config.h` 获取
- 声明实例化 API：
  ```c
  bool foc_encoder_init(foc_encoder_t* enc, const uint16_t* angle_map, foc_encoder_dir_t flash_dir);
  float foc_encoder_track_sector(foc_encoder_t* enc, uint16_t raw_angle);
  foc_encoder_dir_t foc_encoder_detect_direction(foc_encoder_t* enc, const uint16_t* angle_buffer);
  ```
- **移除**全局变量 `extern` 声明（`g_encoder_calib`、`g_motor_flash_cfg`）

### 2. 创建 `foc_q16/foc_encoder.c` — 实例化实现

- 从 `encoder_alignment.c` 复制所有实现代码
- 移除全局 `g_encoder_calib`、`g_motor_flash_cfg`
- 移除 `#include "flash_task.h"`
- `encoder_alignment_init(void)` → `foc_encoder_init(enc, angle_map, flash_dir)`：接收外部 Flash 数据，内部完成验证
- `encoder_track_sector()` 的内部调用 `encoder_read_angle_lut()` → 改为直接访问 `enc->angle_map[]`
- 所有内部 static 函数签名 `encoder_calibration_t*` → `foc_encoder_t*`
- 类型重命名应用到所有函数和局部变量

### 3. 更新 `foc_q16/foc.h` — 嵌入 foc_encoder_t

- `#include "foc_hal.h"` 下方新增 `#include "foc_encoder.h"`
- `foc_config_t::flash_data` (void*) → **保留**，用于传递 `foc_encoder_flash_t*` 到 init
- `foc_context_t` 新增 `foc_encoder_t encoder;` 成员（放在子模块上下文区）
- 新增 `static inline foc_encoder_t* foc_get_encoder_ctx(foc_context_t* ctx)` 访问器

### 4. 更新 `foc_q16/foc_fsm.c` / `foc_fsm.h`

- `#include "encoder_alignment.h"` → `#include "foc_encoder.h"`
- 所有 `g_encoder_calib.*` → `foc->encoder.*`（需配合第3步的上下文嵌入）
- `g_motor_flash_cfg.angle_map` → `foc->encoder.angle_map`
- `g_motor_flash_cfg.direction` → `foc->encoder.flash_direction`
- `motor_flash_config_t* flash_data` cast → 直接使用 `&foc->encoder`
- `MOTOR_DIR_REVERSE/FORWARD/NONE` → `FOC_ENCODER_DIR_REVERSE/FORWARD/NONE`
- `foc_fsm_context_t::flash_data` (void*) → 保留，类型改注为 `foc_encoder_flash_t*`
- `foc_fsm.h` 中 `flash_data` 注释更新

### 5. 更新 `foc_q16/foc.c`

- `#include "encoder_alignment.h"` → `#include "foc_encoder.h"`
- `foc_init()` 中新增编码器初始化：
  ```c
  foc_encoder_t* enc = &ctx->encoder;
  foc_encoder_flash_t* flash = (foc_encoder_flash_t*)ctx->config.flash_data;
  foc_encoder_init(enc, flash->angle_map, flash->direction);
  ```
- `foc_irq_handler()`: `encoder_track_sector(...)` → `foc_encoder_track_sector(&ctx->encoder, ...)`
- `&g_encoder_calib` → `&ctx->encoder`

### 6. 更新 `applications/foc_task.c`

- `#include "encoder_alignment.h"` → `#include "foc_encoder.h"`
- 移除独立的 `encoder_alignment_init()` 调用（已集成到 `foc_init()`）
- `foc_config_t` 初始化中 `.flash_data = &g_motor_flash_cfg` → `.flash_data = &g_encoder_flash`

### 7. 更新 `applications/usart_protocol.c`

- `#include "encoder_alignment.h"` → `#include "foc_encoder.h"` / `#include "foc.h"`
- `extern encoder_calibration_t g_encoder_calib` → 移除
- `extern motor_flash_config_t g_motor_flash_cfg` → `extern foc_encoder_flash_t g_encoder_flash`
- 所有 `g_encoder_calib.*` 访问 → 通过 `foc_get_encoder_ctx()` 获取后访问
- 所有 `g_motor_flash_cfg.*` → `g_encoder_flash.*`
- `motor_flash_config_t` → `foc_encoder_flash_t`

### 8. 更新 `applications/flash_task.c/h`

- `encoder_alignment.h` → `foc_encoder.h`
- `motor_flash_config_t g_motor_flash_cfg` → `foc_encoder_flash_t g_encoder_flash`
- `default_env_set` 中 encoder 条目指向 `&g_encoder_flash`
- `sizeof(g_motor_flash_cfg)` → `sizeof(g_encoder_flash)`
- `task_erase_all()` 中清零 `g_motor_flash_cfg` → `g_encoder_flash`
- `flash_task.h` 中 `extern motor_flash_config_t` → `extern foc_encoder_flash_t`

### 9. 删除旧文件 + 验证编译

- 删除 `applications/encoder_alignment.c`、`applications/encoder_alignment.h`
- CMake 自动发现 `foc_q16/foc_encoder.c`
- `cmake --build` 确认编译通过
