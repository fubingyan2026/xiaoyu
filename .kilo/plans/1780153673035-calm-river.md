# 清理 foc_config.h 中的 Q16.16 预转换宏

## 目标
`foc_config.h` 只保留自然单位参数（float/int），删除所有 `*_Q` 定点数宏。
Q16.16 转换统一在目标文件的初始化阶段完成，不在运行时重复转换。

## 被删除的宏清单（foc_config.h）

| 宏名 | 当前值 | 引用位置 |
|------|--------|----------|
| `CURRENT_SAMPLE_FACTOR_Q` | `FLOAT_TO_Q16_16(CURRENT_SAMPLE_FACTOR)` | `foc_config.h`, `applications/foc_task.c:180` |
| `FOC_PWM_PERIOD_Q` | `FLOAT_TO_Q16_16(FOC_PWM_PERIOD)` | `foc_config.h`, `foc.c:188` (foc_irq_handler) |
| `STATE_PERIOD_Q` | `FLOAT_TO_Q16_16(STATE_PERIOD)` | `foc_config.h`, `foc_fsm.c:152` |
| `ALIGN_THETA_Q` | `FLOAT_TO_Q16_16(0.25f * M_2PI)` | `foc_config.h`, `foc_fsm.c:43,55,157,190,209,267,259` |
| `ALIGN_CURRENT_Q` | `FLOAT_TO_Q16_16(0.50f)` | `foc_config.h`, `foc_fsm.c:151,152` |
| `IF_STARTUP_IQ_Q` | `FLOAT_TO_Q16_16(ALIGN_CURRENT)` | `foc_config.h`, `foc_fsm.c:53,198,242` |
| `IF_STARTUP_OMEGA_Q` | `FLOAT_TO_Q16_16(IF_STARTUP_OMEGA)` | `foc_config.h`, `foc_fsm.c:192,195` |
| `IF_STARTUP_OMEGA_ACC_Q` | `FLOAT_TO_Q16_16(IF_STARTUP_OMEGA_ACC)` | `foc_config.h`, `foc_fsm.c:193` |

仍保留的非 Q16.16 整数常量：`PLL_ELE_KP`、`PLL_ELE_KI`、`FOC_FSM_*`、`FOC_FSM_ALIGN_TIMEOUT_CNT`、`MOTOR_POLES` 等。

## 实施步骤

### 1. `foc.h` — 在 `foc_context_t` 中新增 Q16.16 预计算字段

在 `struct foc_context` 的控制状态区新增以下字段（10 个）：

```c
q16_16_t pwm_period_q;             // FOC_PWM_PERIOD 转为 Q16.16（PLL dt）
q16_16_t state_period_q;           // STATE_PERIOD 转为 Q16.16（状态机周期）
q16_16_t pll_kp_q;                 // config.pll_kp 转为 Q16.16
q16_16_t pll_ki_q;                 // config.pll_ki 转为 Q16.16
q16_16_t pll_speed_limit_q;        // config.pll_speed_limit 转为 Q16.16
q16_16_t align_theta_q;            // 对齐角度 0.25 * 2π 转为 Q16.16
q16_16_t align_current_q;          // 对齐电流 0.50A 转为 Q16.16
q16_16_t if_startup_iq_q;          // IF 启动 Iq 转为 Q16.16
q16_16_t if_startup_omega_q;       // IF 启动角速度转为 Q16.16
q16_16_t if_startup_omega_acc_q;   // IF 启动角加速度转为 Q16.16
```

### 2. `foc_config.h` — 删除所有 `*_Q` 宏及相关注释块

删除 8 个 `*_Q` 宏定义及其 `@def` 注释块，保留对应的 float/int 原值宏：
- 保留 `CURRENT_SAMPLE_FACTOR 0.0096683555f`
- 保留 `FOC_PWM_PERIOD (0.00005952381f)`
- 保留 `STATE_PERIOD (0.001f)`
- 保留 `ALIGN_CURRENT (0.50f)` 等

新增注释说明：转换在 foc_init() 中完成。

### 3. `foc.c/foc_init()` — 预计算所有 Q16.16 值

在 `foc_init()` 中，PI 控制器初始化之后添加预计算代码块：

```c
// 预计算常用 Q16.16 值（避免运行时重复转换）
ctx->pwm_period_q = FLOAT_TO_Q16_16(ctx->config.pwm_period_s);
ctx->state_period_q = FLOAT_TO_Q16_16(ctx->config.fsm_period_s);
ctx->pll_kp_q = FLOAT_TO_Q16_16(ctx->config.pll_kp);
ctx->pll_ki_q = FLOAT_TO_Q16_16(ctx->config.pll_ki);
ctx->pll_speed_limit_q = FLOAT_TO_Q16_16(ctx->config.pll_speed_limit);
ctx->align_theta_q = FLOAT_TO_Q16_16(0.25f * M_2PI);
ctx->align_current_q = FLOAT_TO_Q16_16(ALIGN_CURRENT);
ctx->if_startup_iq_q = FLOAT_TO_Q16_16(ALIGN_CURRENT);
ctx->if_startup_omega_q = FLOAT_TO_Q16_16(IF_STARTUP_OMEGA);
ctx->if_startup_omega_acc_q = FLOAT_TO_Q16_16(IF_STARTUP_OMEGA_ACC);
```

### 4. `foc.c/foc_irq_handler()` — 使用预计算值

- `FOC_PWM_PERIOD_Q` → `ctx->pwm_period_q`
- `FLOAT_TO_Q16_16(ctx->config.pll_kp)` → `ctx->pll_kp_q`
- `FLOAT_TO_Q16_16(ctx->config.pll_ki)` → `ctx->pll_ki_q`
- `FLOAT_TO_Q16_16(ctx->config.pll_speed_limit)` → `ctx->pll_speed_limit_q`

### 5. `foc_fsm.c` — 逐处替换宏引用

文件顶部新增 `#include "foc_config.h"`（确认已有），所有 `*_Q` 宏替换为 `foc->xxx_q`：

| 旧（宏） | 新（上下文字段） |
|-----------|-----------------|
| `ALIGN_THETA_Q` | `foc->align_theta_q` |
| `ALIGN_CURRENT_Q` | `foc->align_current_q` |
| `STATE_PERIOD_Q` | `foc->state_period_q` |
| `IF_STARTUP_IQ_Q` | `foc->if_startup_iq_q` |
| `IF_STARTUP_OMEGA_Q` | `foc->if_startup_omega_q` |
| `IF_STARTUP_OMEGA_ACC_Q` | `foc->if_startup_omega_acc_q` |

共约 17 处替换。

### 6. `applications/foc_task.c:180` — 端口配置初始化

```c
.current_sample_factor_q = CURRENT_SAMPLE_FACTOR_Q,
```
→
```c
.current_sample_factor_q = FLOAT_TO_Q16_16(CURRENT_SAMPLE_FACTOR),
```

### 7. 验证编译

`./build.sh` 确认所有文件编译通过。
